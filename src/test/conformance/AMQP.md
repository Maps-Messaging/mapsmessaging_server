# AMQP 1.0 Java Conformance Suite

Authoritative source: OASIS AMQP 1.0 Core Specification.

The suite validates protocol header negotiation, frame layout, SASL negotiation, connection/session/link lifecycle, transfers, dispositions, settlement, and flow control using normative OASIS requirements.

Source: https://docs.oasis-open.org/amqp/core/v1.0/os/
